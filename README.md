# Sugrob — снег на рабочем столе Windows

Снег идёт поверх рабочего стола и окон, копится сугробами на окнах и панели задач, смахивается
курсором, из него лепятся снеговики. Есть гирлянды на окнах, снегоуборщик и живые обои.
Клики проходят сквозь снег. Windows 10 (22H2) и 11, x64.

## Установка
Запустите `Sugrob.exe` — он предложит установиться в `%LOCALAPPDATA%\Programs\Sugrob`
(права администратора не нужны): ярлык в «Пуске», автозапуск, удаление через «Параметры → Приложения».
«Нет» — просто запустится без установки. Программа не подписана сертификатом, поэтому при первом
запуске SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».

## Управление
Снежинка в трее: левый клик — пауза, правый — меню со всеми настройками.

| Клавиши | Действие |
|---|---|
| Ctrl+Alt+Shift+S | пауза |
| Ctrl+Alt+Shift+W | лёгкий / ровный снег / метель |
| Ctrl+Alt+Shift+стрелки, Пробел | ветер, штиль |
| Ctrl+Alt+Shift+T | варежка / лопата |
| Ctrl+Alt+Shift+B | лепить снежки и снеговиков (Esc — выход) |
| Ctrl+Alt+Shift+C | убрать весь снег |
| Ctrl+Alt+Shift+P | вызвать снегоуборщик |
| Ctrl+Alt+Shift+G / H | режим / форма гирлянд |
| Ctrl+Alt+Shift+F | форма снежинок |
| Ctrl+Alt+Shift+L | живые обои: выкл / домик / крыльцо |
| Ctrl+Alt+Shift+Q | не мешать в развёрнутых окнах |

## Бережёт компьютер
* Рисует на видеокарте (Direct2D + DirectComposition), обычно ~0,5 % процессора при 60 кадрах/с.
* «Плавность → Как у монитора»: каждый монитор рисуется со своей частотой (например 240 Гц и 60 Гц);
  на 240 Гц нагрузка примерно в 3–4 раза выше.
* Над развёрнутыми и полноэкранными окнами (видео, игры) снег не идёт и не считается.
* На батарее и в режиме экономии — меньше снега и ≤30 кадров/с.
* Когда компьютер заблокирован — стоит. Если в Windows выключены анимации — падающего снега нет (как у оригинала).
* Смотрит только на границы окон, содержимое не читает; в интернет не ходит.

Настройки: `%APPDATA%\Sugrob\settings.json`.

## Обновления
Программа сама проверяет [релизы этого репозитория](https://github.com/MDFillin/sugrob/releases)
(через минуту после запуска и раз в 6 часов), скачивает новую версию, проверяет SHA-256 и ставит её
при следующем запуске или сразу через меню «Обновить до X.Y.Z». Отключается галочкой
«Обновляться автоматически».

Выпуск новой версии: поднять `<Version>` в `src/Sugrob/Sugrob.csproj`, `dotnet publish`,
создать релиз с тегом `vX.Y.Z` и приложить `Sugrob.exe` и `Sugrob.exe.sha256`.

## Сборка
Нужен .NET 10 SDK.
```
dotnet publish src/Sugrob -c Release -o publish
```
Получится один `publish/Sugrob.exe` (~37 МБ), которому не нужен установленный .NET.
Иконка: `powershell -ExecutionPolicy Bypass -File tools/make-icon.ps1`.
Отладка: `SUGROB_PROFILE=1` пишет замеры и события в `%APPDATA%\Sugrob\perf.log`.
